# Demo 講稿（4 分鐘 Live Demo）

畫面：瀏覽器開 http://localhost:8501（`make open`）。左：對話。中：裝置模擬器。右：即時狀態、警報、後台事件。

## 開場前 30 分鐘

1. `make up`，等 `docker compose ps` 三個服務都 healthy（ui 也是）。
2. `make rehearse`：用真實頁面跑完整個故事，應該顯示 `1 passed`。
3. **關閉 Wi-Fi**，再按頁面上的「🔄 重置 Demo」，確認一切照常。這就是離線證明。
4. 瀏覽器全螢幕。不要開 `.env`。終端機留一個 `make logs` 當備用畫面。

## 備案

| 狀況 | 做法 |
| --- | --- |
| 頁面當掉或卡住 | 終端機 `make demo-cli`（同一個故事，純文字）。`ARGS=--step` 可每個場景暫停 |
| 場景按了沒反應 | 等 2 秒（頁面每 2 秒更新）。仍沒有就按「🔄 重置 Demo」再來一次 |
| Agent 沒聽懂 | 只用快捷按鈕。假模型只認固定說法 |
| 容器異常 | `make demo-reset`（重啟資料庫與 API，約 10 秒） |
| 完全無法啟動 | 播放備用螢幕錄影（請在彩排時自己錄一份） |

## 可能的提問

- **為什麼用假模型？** 離線、免費、結果可重現。它是真正的 LangChain 模型，跑的是同一個 `create_agent` 工具迴圈。換真 LLM 只改 `bootstrap._build_model`。
- **怎麼確保安全？** 通報由規則決定。Agent 的 Tool 綁定單一長者。不診斷、不調藥量。門檻是 Demo 值，需臨床審閱。
- **怎麼上 AWS？** 見對照表。狀態（時鐘、警報、訂閱）要搬到共享服務才能多實例。
- **個資呢？** log 只記事件與 trace-id，不記對話內容。正式環境要加加密、授權與保存期限。
